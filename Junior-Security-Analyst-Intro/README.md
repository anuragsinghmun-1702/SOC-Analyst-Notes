Objective 
Understand the role of a Junior Security Analyst, the purpose of a Security Operations Center (SOC), and the responsibilities involved in monitoring, detecting, investigating, and responding to security threats.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
What is Security Operations Center(SOC)?
A Security Operations Center (SOC) is a centralized team responsible for monitoring, detecting, analyzing, and responding to cybersecurity incidents within an organization in a real time.

Main Goals
-Detect security incidents.
-Investigate suspicious activities.
-Respond to threats.
-Protect oraganizational assets.
-Maintain security visibility.

----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
What is a Junior Security Analyst?
A Junior Security Analyst is the first line of defense within a SOC.

They are responsible for:
-Monitoring security alerts.
-Investigating suspicious activites.
-Collecting evidence.
-Documenting findings.
-Escalating confirmed threats.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Responsibilities of a SOC Analyst
Monitoring:
Continuously monitor:
-Endpoint activity.
-User activity.
-Network traffic.
-Security alerts.

Examples:
-Multiple failed logins.
-Malware detections.
-Suspicious PowerShell activity.
-Unusual network connections.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Alert Triage:
Determine whether an alert is:
-True Positive.
-False Positive.
-Benign Activity.

Questions to Ask:
-What happened?
-Who is involved?
-When did it occur?
-Is the activity malicious?
-What is the impact?
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Investigation:
Analyze available evidence.

Data Sources:
-Windows Event Logs.
-Sysmon Logs.
-Firewall Logs.
-SIEM Alerts.
-EDR Alerts.
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Incident Response:
Once malicious activity is confirmed:
1. Identify.
2. Investigate.
3. Contain.
4. Eradicate.
5. Recover.
6. Document.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Escalation:
If an incident is serious or requires deeper analysis, it is escalated to senior analysts.

Escalation Information:
If an incident is serious or require deeper analysis, it is escalated to senior analysts.

Escalation Information:
-Incident summanry.
-Impact assessment.
-Evidence collected.
-Affected systems.
-Recommended actions.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

SOC Analyst Daily Workflow:

                        Alert Generated
                              ↓
                        Review Alert
                              ↓
                      Validate Alert
                              ↓
                     Investigate Evidence
                              ↓
                     Determine Severity
                              ↓
                      Document Findings
                              ↓
                    Escalate if Required
                              ↓
                        Close Incident

Cyber Security Domains:
1. Blue Team-
Focused on defense.
Responsibilites:
-Monitoring.
-Detecting.
-Incident Response.
-Threat Hunting.

2. Red Team-
focused on attack simulation.
Responsibilites:
-Penertration Testing.
-Adversary Emulation.
-Vulnerability Discovery.

3. Purple Team-
Combine Blue Team and Red Team knowledge to improve security defenses.
